# Security Policy

## Reporting Security Issues
If you discover a potential vulnerability or security concern in Cryptonite:
1. Do not report security vulnerabilities through public GitHub issues.
2. Maintain isolated credentials: API keys must always be generated with withdrawals disabled, restricted by IP address, and loaded exclusively via environment variables or secret vaults.
3. Cryptonite browser terminals and AI agent layers must never have direct custody or transmission access to exchange private keys.
